# 领域边界

跟踪中欧班列箱货编组、口岸节点、异常处置与交付承诺。

现有领域资料围绕以下边界组织：

- 订单与箱货谱系
- 装载与编组
- 口岸和换装节点
- 异常责任
- 目的站交接

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 节点顺序与责任主体

箱货节点固定为：订单受理 → 货代装箱 → 进站编组 → 南昌始发 → 抵达霍尔果斯口岸 →
口岸查验放行 → 换装完成 → 境外铁路区段在途 → 抵达比什凯克目的站 → 目的站交接交付。

- 回执只能把箱货推进到**紧邻的下一节点**；跳节点回执被拒绝并留痕，节点不变。
- 每个节点对应唯一责任主体（货代 / 班列运营方 / 铁路承运方 / 口岸查验人员 /
  目的站交接人员），查询箱货时同时给出当前责任人与下一责任人。

## 回执幂等与单证一致

- 回执以回执编号去重：同一回执重复到达返回 `duplicate`，不重复推进、不重复记账。
- 同一回执编号指向不同箱货或节点属于错误，直接拒绝。
- 箱号相同但回执重量与建档重量不符、或单证清单发生增减时，不推进节点，
  箱货进入核对（`review`）并登记差异明细；核对处置可修订建档数据后放行。
- 因冻结或跳节点被拒的回执单独登记，重复到达不重复产生拒收回执；处置放行后
  原回执可重新到达并正常推进。

## 局部冻结

- 危险属性查获与查验异常（如暂扣）只冻结**受影响的箱货**，冻结原因与责任方留痕。
- 冻结箱的推进回执被拒绝；同一班列其他箱货的查验、换装、在途与交付不受影响。
- 处置结论区分放行与继续暂扣；放行后箱货从原节点继续，不产生虚假节点。

## 拆分、合并与改配

- 拆分：母箱重量核减，子箱以谱系（parents）指回母箱，从订单受理节点重新走完旅程。
- 合并：仅允许同一订单、同一节点、非冻结/核对中的箱货合并；原箱标记为不活跃，
  新箱记录全部来源箱；谱系支持多母箱向上追溯与子箱向下查询。
- 改配：暂扣箱改走下一班时记录原班列、新班列、车皮、原因与承诺影响；
  已取得的口岸之后回执作废、节点回到口岸待命，凭新班列旅程的新回执重新推进；
  可同步登记对客户的修订承诺区间，原承诺区间保留可对照。

## 延误与交付承诺

- 班列延误登记原因、影响范围与修订 ETA，订单预计交付取班列当前有效 ETA。
- 预计交付晚于承诺截止日时，订单解释明确标注承诺受到影响；改配则给出修订承诺。
- 目的站交接以交付回执加交接凭证完成，交付时间以事件记录为准，重启重放不变。

## 跨停机续推

- 所有状态变更只以追加事件（JSONL，append + fsync）落盘，内存状态由重放投影得到。
- 进程重启后重放日志恢复订单、箱货、班列、已处理回执索引与事件序号，
  冻结、核对、延误和改配等跨越停机的处置可继续推进。
